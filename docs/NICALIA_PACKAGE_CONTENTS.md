# Contenido paquete futuro Nicalia

## Incluir

- `app/`
- `public/`
- `public_html/.htaccess`
- `views/`
- `vendor/` y `composer.*` si el hosting no ejecuta composer

## Excluir

- `.git/`
- `.next/`
- `node_modules/`
- Docker/Next
- `docs/`
- `ops/`
- `nginx/`
- logs locales
- `.env` local o secretos

## Nota

El paquete debe conservar `/no/`, landings de zona y reformas vivas. Reformas no se anade al sitemap salvo decision posterior. Si se incluyen variables SMTP en el hosting, el host correcto es `masqueclima.es`.
